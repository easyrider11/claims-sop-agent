# Live scenario transcripts

Generated by `python -m scripts.run_scenarios` against real OpenAI models, 2026-10-13/14. The test account
allowed only 50 requests per day per model, so the scenarios were spread over four small models; each
section names its model. Scenarios touched by the final review fixes (demo, verification hint, frustrated
caller, representative, Ma Tian) were re-run after the fixes and are shown in their re-run form.

Under each agent reply is the harness trace: phase change · SOP steps · detected emotion/scope · who wrote
the reply (`llm:...`, or `template` when the model was unavailable or the output guard rejected it).

All 11 scenarios pass their checks against a live model: no claim data before verification, plus the
expected final phase, selected claim and email choice. Total model spend for all runs: about $0.19.
